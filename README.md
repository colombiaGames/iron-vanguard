# Iron Vanguard

A run and gun game made with Phaser 3. Graphics are drawn in code, and sound effects are CC0 samples.

## Run

Serve the folder with any static server:

```
npx serve .
```

## Controls

| Action | Keyboard |
| --- | --- |
| Move | Arrows or A D |
| Aim up | Up or W |
| Crouch | Down or S |
| Shoot / knife | J or Z |
| Jump | K, X or Space |
| Grenade | L or C |
| Mute | M |
| Pause | P or Esc |

Gamepads work too.
